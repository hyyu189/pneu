# handoff/archive

Historical and superseded handoff documents. Every file here was correct when
it was written and is kept for provenance and reasoning history; **none of it
is a guide to current behavior.** Each file carries a one-line
`> Status:` header naming why it moved.

For what is true now, read `README.md`, `docs/`, `PRINCIPLES.md`, and
`decision.md`. The files still in `handoff/` are the ones that remain the best
statement of a live fact.

Two Antigravity records stay in `handoff/` rather than moving here, even
though they are historical: the `decision.md` 2026-08-05 entry cites those
exact paths, and that ledger is append-only.
