# Live findings — 2026-07-21 cutover, E2E matrix, and demo production

Field evidence from the RC10 live cutover and the submission-video production.
Message IDs refer to the archive worktree's mailbox ledger
(`../2026-OAI-Build-Week/.roundtable/`). Maps to BRIEF.md roadmap items 1–3.

## Confirmed product defects

1. **Hermes reply-template argument construction** (roadmap #1).
   Replies arrive with CLI flags leaked into the body and the token in the
   `kind` field. Specimens: `20260721T222638Z-hermes-to-claude-28954`
   (`kind=cross_hermes_ok`, body `--kind reply --refs ...`),
   `20260721T222645Z-hermes-to-claude-29195`, `20260721T224925Z-...-52776`,
   `20260721T225127Z-...-54352`.
2. **Fenced `rt-inbox` silently hides malformed mail** (roadmap #2).
   Malformed messages are invisible to the fenced listing while the file sits
   in `new/` and keeps triggering the watcher — wake loops with "empty" drains;
   surfaced only via raw `ls`. Two reproduced specimens (29195, 52776).
   `rt-ack --fenced <raw-id>` works and breaks the loop. Expected behavior:
   surface as malformed instead of hiding.
3. **Hermes drain contract: processed mail not archived `new/` → `cur/`**
   (roadmap #1; Codex RC6 finding). Watcher stalls at "waiting for inbox to
   drain"; first wake works, second does not re-arm.
4. **Hermes TUI lifecycle arming** (roadmap #1; Codex/Hermes finding):
   plugin listens for `on_session_start` but TUI init emits
   `on_session_reset`; `inject_message` lacks a CLI reference in TUI mode.

## Confirmed ergonomics/UX findings

5. **Tripwire arming is model-dependent** (roadmap #3). A seat model arming
   via shell `&` trips the harness background-operator approval prompt and
   freezes unattended seats; guidance must be product-owned (or
   `rt-wait-inbox` should self-daemonize). Stage workaround: CLAUDE.md note +
   allowlist.
6. **Idle seats with zero user turns never arm.** SessionStart hook context
   alone does not start a turn; mail waits until a first interaction. Document
   or redesign.
7. **Slow-turn seats miss wake windows** (roadmap #3). A busy Codex seat took
   ~5 minutes to drain during filming; wake latency expectations and backlog
   behavior need product-level documentation.
8. **`open`-launched processes inherit the caller's `RT_*` env** — a seat
   launcher run from another seat's shell propagates the wrong `RT_FROM`
   (rt-hermes correctly failed closed). Consider explicit env scrubbing in
   launchers.

## Retracted during investigation (do not implement)

- Quiet `ack-*` files waking the watcher: refuted by Codex code-level evidence

  bug (#2) plus SessionStart drains.
- The Hermes "keyboard injection" incident was cmux focused-surface routing
  drift of the user's own input, not Roundtable transport (fish history
  evidence, 15:20:08).
